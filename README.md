# Vojtech Vahala - Photography Website

A modern, responsive website for Czech photographer Vojtech Vahala. This website showcases the photographer's portfolio, services, and provides a way for clients to get in touch. Live <a href="">here!</a>

## Features

- **Portfolio Gallery**: Browse through the photographer's work with an interactive gallery
- **Services**: Information about photography services offered
- **About Me**: Learn more about the photographer
- **Contact Form**: Get in touch with the photographer
- **Responsive Design**: Optimized for all devices

## Tech Stack

- React + Vite
- Tailwind CSS
- Cloudinary API: Connected through a simple custom API to fetch images from Cloudinary
- Modern web technologies
